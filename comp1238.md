### Midterm Important

## Week 1
- Origins of Writing: Writing began with record-keeping.
- Cuneiform: Wedge-shaped symbols pressed into clay.
- Cuneiform Numbers: Base-60 number system.
- Ancient Number Systems: Egyptian and Roman numerals.
- Written Stories: Preserving literature and history.
- Writing Systems: Scripts can represent different languages.
- Printing Revolution: Printing made books widely available.
- Printing Terminology: Fonts, typefaces, serifs, and typesetting.
- Typewriters: Standardized text and introduced carriage returns.

## Week 2
- Bits and Bytes: Bits store binary values; 8 bits make a byte.
- Computer Memory: RAM is temporary; HDDs and SSDs store data long-term.
- Units of Measurement: KB, MB, GB, and TB measure data storage.
- Representing Numbers: Binary uses 0s and 1s to represent numbers.
- Negative Numbers: Signed numbers represent positive and negative values.
- Fractional Numbers: Floating-point stores numbers using a significand and exponent.
- Memory as Bytes: Computer memory is a sequence of addressed bytes.
- Representing Text: Character encoding maps characters to numbers.
- ASCII: A standard code for representing English letters, digits, and symbols.
- Files: Files store named sequences of bytes.
- Text vs. Binary Files: Text files represent characters; binary files store other types of data.
- Number Systems and Bases: Decimal, binary, octal, and hexadecimal use different bases.
- Further Reading: Additional resources explain binary numbers and early computers.

## Week 3
- Historical Text: Layouts helped organize and explain information.
- Tables and Ledgers: Rows and columns organize data.
- Basic Text Structure: Text uses lines, whitespace, and paragraphs.
- Special Characters: Symbols have different meanings depending on context.
- Markup Languages: Add formatting and structure to text.
- Markdown: Simple syntax for formatted text.
- Other Markup Languages: HTML, XML, YAML, and wiki text.
- Tim Berners-Lee: Created HTML and the first web browser and server.
- Browsers and Rendering: Convert web code into visible pages.
- Structured Data: Organizes information into consistent formats.
- JSON: Stores data using key-value pairs and arrays.
- XML: Uses customizable tags to structure data.
- Serialization: Converts data into a format for storage or transfer.
- Human vs. Machine Readability: Balances readability with processing efficiency.
- Escaping Characters: Prevents special symbols from being interpreted as markup.

## Week 4
- Keyboard Skills: Touch typing improves speed and focus.
- Keyboard Layouts: QWERTY, QWERTZ, and Dvorak.
- Modifier Keys: Shortcuts perform actions quickly.
- Keyboard Types: Mechanical and rubber dome keyboards.
- Ergonomics: Proper posture prevents strain.
- Keyboard Events: Key presses and releases trigger events.
- Programmable Keyboards: Customize keys and shortcuts.
- Touch Typing: Accuracy and regular practice improve speed.
- Text Editors: Create and modify plain text files.
- Word Processors vs. Editors: Rich formatting vs. plain text.
- IDEs: Combine editors with coding and debugging tools.
- Vim and Emacs: Powerful, customizable text editors.
- VS Code: Popular editor with extensions and useful features.
- Finding Text: Ctrl + F searches within documents.
- Search and Replace: Find text and replace matching content.
- Wildcards: Match file patterns, such as *.txt.
- Regular Expressions: Search for complex text patterns.
- GitHub Pages: Hosts websites from repositories.
- github.dev: Edit GitHub repositories in a browser.
- Editor Features: Syntax highlighting, previews, and multiple cursors.
- Version Control: Track changes and manage code with Git.

## Week 5
- Command Line (CLI): Control computers using text commands.
- CLI History: Evolved from paper terminals to screens.
- CLI as a Chatbot: Commands give input; computers return output.
- CLI Structure: Commands, arguments, and options.
- Why Use CLI: Speed, precision, and automation.
- SSH: Securely connect to remote computers.
- Bandit Game: Practise command-line skills through challenges.
  ls: List files and directories.
  pwd: Show the current directory.
  cd: Change directories.
  man: Display command manuals.
  cat and less: View file contents.
- Tab Completion: Automatically complete commands and filenames.
- Terminal Setup: Access the command line on Windows, Mac, or Linux.
- File Commands: cp copies, mv moves, and mkdir creates directories.
- Utilities: ping tests connections, grep searches text, and wc counts text.
- Redirection (>): Send command output to a file, overwriting it.
- Appending (>>): Add command output to the end of a file.
- Piping (|): Send one command's output into another command.
- Unix Philosophy: Small tools work together to perform complex tasks.
  scp and sftp: Transfer files securely between computers.
- TUI: Text-based interfaces provide interactive terminal displays.
  htop: Monitor system resources and running processes.
  tmux: Manage multiple terminal sessions that can persist remotely.
